# TokenBar Promo

Editable Remotion project and rendered Chinese promotional video for TokenBar.

## Design read

Developer-focused macOS product film with an Apple-adjacent, sober graphite visual language. Real TokenBar screenshots are the evidence layer; generated imagery is atmospheric support only.

## Creative dials

- Design variance: 6/10
- Motion intensity: 7/10
- Visual density: 4/10

## Deliverables

- `project/`: editable Remotion source
- `capture/screenshots/`: real TokenBar UI captures
- `project/public/generated/`: generated atmospheric imagery
- `project/public/audio/`: Edge TTS narration and captions
- `stills/`: representative rendered frames
- `output/`: final MP4
