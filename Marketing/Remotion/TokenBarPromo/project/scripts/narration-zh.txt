AI 编程代理执行得越来越快，但一次错误的工作区、模型或预算判断，就可能在几秒内带来真实成本。

TokenBar 是 macOS 菜单栏里的本地策略闸门。在 Agent 真正触碰仓库和供应商额度之前，它先检查工作区、供应商、模型、公司 Key、单次成本与预算投影，并给出 ALLOW、WARN 或 BLOCK。

你可以在守卫面板完成一次运行前检查，清楚看到当前决定、原因、预计花费和回退方案。

OpenAI、Anthropic、OpenRouter、MiniMax、Codex 与本地代理用量，被汇总到一个真实的状态界面。

每个仓库都能用 tokenbar.yml 携带自己的策略，设置允许的供应商、首选模型、单次上限、日预算与月预算。

CLI、本地 API，以及 Codex 和 Claude Code hooks，共享同一套策略引擎。

数据处理保持本地优先，API 只监听 127.0.0.1，缺失数据也不会被伪装成零成本。

TokenBar 为每次 Agent 运行给出清晰结论：允许、提醒或阻止。策略先行，执行更稳。
